# 🏅 Olympic Games Data Analysis Dashboard | Power BI

## 📊 Project Overview

This project is an interactive **Olympic Games Data Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes Olympic athlete and medal data to provide insights into **medal performance, athletes, countries, gender distribution, and overall Olympic trends**.

The main objective of this project is to transform raw Olympic data into an interactive and easy-to-understand business intelligence dashboard.

---

## 🎯 Project Objectives

- Analyze Olympic medal performance across countries.
- Compare **Gold, Silver, and Bronze** medal achievements.
- Analyze athlete participation and performance.
- Explore medal distribution by gender.
- Identify countries with strong Olympic performance.
- Provide interactive visualizations for easier data exploration.

## 📈 Dashboard Pages

### 🏠 Home

Provides an introduction to the dashboard and navigation to the different analytical sections.

### 📊 Overview

Provides a high-level view of Olympic performance, including:

- Total Gold Medals
- Total Silver Medals
- Total Bronze Medals
- Medal distribution
- Country-level performance
- Gender-based analysis

### 🥇 Medals by Athletes

Analyzes athlete-level medal performance and provides insights into medal achievements.

### 🏃 Athletes

Provides an overview of Olympic athletes and their participation/performance.

### 🌍 Country

Analyzes Olympic performance at the country level and allows comparison between countries.

---

## 🔍 Key Insights

The dashboard allows users to:

- Identify countries with the highest medal achievements.
- Compare Gold, Silver, and Bronze medal performance.
- Analyze differences in medal distribution between male and female athletes.
- Explore athlete-level Olympic performance.
- Compare countries using interactive visualizations.
- Identify patterns and trends in Olympic medal data.
